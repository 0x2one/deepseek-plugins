# 一键收起工作区 (Collapse all workspaces)

在侧边栏「工作区」标题右侧的按钮组末尾加一个按钮，一次收起所有已展开的工作区分组（含「未分组」）。

- 只在分组视图出现：侧边栏收成 56px 图标栏、展开行内搜索、或切到「扁平」会话列表（那时标题是「会话」且没有分组）时，按钮跟宿主自己的头部按钮一起隐藏。
- 没有已展开的分组时，图标变淡并带 `aria-disabled="true"`，点击不做任何事。
- 折叠动作逐个触发各分组行自己的展开开关，展开状态仍由宿主自己的视图状态持久化，插件不写第二份状态。
- 收起后会通过一个视觉隐藏的 `role="status"` 区域播报「已收起 N 个工作区」，列表本身的变化是视觉反馈。
- 键盘可达：可 Tab 聚焦、Enter/Space 触发，焦点环沿用宿主 token；被搜索框顶掉显示时会把焦点交给搜索框。

## 已知限制

在嵌套工作区视图（`nestWorkspaces`）里，如果某个子工作区分组自己处于展开状态、而它的父分组是收起的，该子分组行不会被挂载，本按钮只能收起已挂载的分组行，因此它会在下次展开父分组时仍以展开状态出现。

## 实现说明

当前版本的 `@deepseek-ai/dsh-client-ui-workspace` 把「工作区」标题行（标题、搜索、视图选项、新增工作区）渲染在自己的组件里，没有对外声明 header actions 插槽，插件无法通过 slot 进入这一位置。本插件按宿主发布的 `data-sidebar-workspace-header` 钩子把按钮挂到该标题行末尾，用 `--dsw-*` 主题 token 复制宿主图标按钮的尺寸与悬停样式，不引入任何 Harness Client 包。

因此它依赖三个宿主事实：标题行带 `data-sidebar-workspace-header`，分区列表带 `data-sidebar-list-area`，分组行带 `data-row-key="workspace:…"` 与 `aria-expanded`。宿主若更换这些属性或改变头部结构，按钮会退回为不显示（15 秒内找不到标题行时在控制台告警 `[sidebar-collapse-all] workspace header not found`）。

## 关闭插件时

按钮、播报区域与样式一并移除，工作区的展开状态、会话列表和其他插件的样式都不受影响。
