# 待办

左侧栏里的私人待办看板：待办、进行中、已完成三列。数据只保存在本机，Agent 完全看不到。

## 怎么用

- 点击左侧栏的**待办**图标（在插件与自动化任务之后），或输入 `/todo` 打开面板。
- 顶部输入一行标题，**回车**即保存；新条目出现在「待办」列顶部。
- 拖动卡片可以换列与调顺序：拖进「已完成」就是完成，重复任务会自动生成下一次。
- 点卡片展开编辑：备注、截止日期（可选具体时间）、优先级、标签、重复规则。
- 键盘：`/` 搜索、`c` 聚焦输入、`Enter` 编辑、`x` 完成、`Alt+方向键` 调序或换列、`Esc` 取消。

## 行为说明

- **角标**显示未完成数量；有逾期时改用警示色。超过 99 显示 `99+`。
- **提醒**只在 Harness 页面打开时生效：带具体时间的任务到点弹一次应用内提示。关闭期间过期的任务不会补发提示，只在下次打开时显示为逾期。
- **重复任务**：每天 / 每个工作日 / 每周 / 每月，依据截止日期推算；完成后生成下一次，取消完成时若下一次仍未被改动会一并撤回。
- **归档**：完成后卡片留在「已完成」列，手动归档后才离开看板；已归档视图里可以恢复或永久删除。

## 数据

- 文件：`$DSH_HOME/todo/todos.json`（默认 `~/.dsh/todo/todos.json`），原子写入。
- 归档全部、删除、重排前会把当前文档快照到 `$DSH_HOME/todo/backups/`，默认保留最近 10 份。
- 文档损坏时，原文件会改名为 `todos.corrupt-<时间>.json` 保留，插件以空文档启动。

## 边界

- 不与 Agent 共享数据，不注册工具、不写会话日志。
- 不做子任务、协作、云同步、系统通知。
- 左侧栏收起时，角标仍随图标显示；极窄图标格下角标可能被裁切，属已知限制。
